启用步骤与真实写入开关
  1. 启动服务：双击仓库根目录的 start.bat（或在该目录执行 python server.py），浏览器打开 http://127.0.0.1:8765。服务只监听本机，未注册开机自启，窗口关闭即停止；可在桌面建快捷方式指向 start.bat。
  2. 浏览器右键：Chrome/Edge → 扩展程序 → 开发者模式 → 加载已解压的扩展程序 → 选 extensions/chrome。之后选中文字右键「Quick capture to workbench」即可录入。
  3. Windows 文件右键：PowerShell 运行 windows/install.ps1（写 HKCU，无需管理员）；卸载用 windows/uninstall.ps1。
  4. 命令行同步：python sync.py 预览，python sync.py --run 执行；可挂到任务计划做定时同步。
  5. 开启真实写入（三步缺一不可）：config.json 里 dry_run=false、dida.enabled=true、sync.project_id 填目标清单 ID；token 由 python oauth.py auth 授权后自动写入，无需手填。执行按钮仍会二次确认。
  6. 当前模式以页面顶部状态条为准：DRY-RUN 只生成计划，LIVE 会真实写入飞书与滴答。dry_run 同时控制右键录入，改完无需重启服务。
  7. 空标题记录会被同步跳过，不会在滴答里生成 (untitled) 任务。
